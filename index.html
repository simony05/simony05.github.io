RTX RF Signal Classifier

C++ · RISC-V · SIMD · BLAS · SLEEF

  • A C++ tensor framework for real-time RF signal classification on RISC-V, built with RTX. It runs a CNN that classifies signals from 128 raw I/Q samples on low-power hardware, where a full CPU or GPU isn't an option.
  • Tensor shapes are fixed at compile time and enforced with C++20 concepts, so sizes resolve through constexpr and mdspan accessors inline down to plain indexing. That lets the compiler unroll loops and vectorize matrix operations with the RISC-V Vector Extension.
  • An expression system defers evaluation until it sees the whole expression, fusing chains like relu(conv + bias) into one pass over the data instead of one pass per operation. This avoids intermediate tensors and cuts memory reads and writes.
  • A custom memory buffer reserves one contiguous block up front and serves allocations by advancing a pointer, which makes allocation cheaper and more predictable than a general-purpose allocator and keeps data cache-friendly.
  • General-purpose libraries like PyTorch carry runtime overhead to support every workload. Since our model and target hardware are known ahead of time, we moved as much work as possible to compile time and used BLAS and SLEEF for the core math.
